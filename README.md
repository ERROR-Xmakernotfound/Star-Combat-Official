# Star-Combat-Official

## Development log
### 11/26/2026
**Added the BETA TEST token**

To make it easier to tell if you're playing on a beta version of the game, at the top right corner of the screen i added a transparent token that has the word `BETA` on it.

**Modified HUD**

To get more clone headroom, I changed the hud so when entering the city the ATK_HP display text, Wave display text, boss_hp text and boss_name text dissapear.

**Modified attack system**

Due to the attack system creating way too many clones, I disabled attacks when inside of the city, this is necessary because the city needs as many free clones as possible. (even though turbowarp grants infinite clones, I still want the city to be usable in vanila scratch.)

**Modified enemy system**

Changed the enemy system so entering the city causes them to disappear, this also applies to bosses.

**Created Repository & DevLog**

This is the day I created the Repo for Beta versions of the game and the devlog, if you are reading this, welcome :)
